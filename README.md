# phizou.github.io

Personal portfolio for Peter Hagen. It is a data, analytics, and BI engineering portfolio with consulting and data-product pages.

Built with Astro + Tailwind. Pushes to `master` deploy to GitHub Pages through GitHub Actions.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/ (gitignored)
```

Project case studies live in `src/content/projects/`. See `CLAUDE.md` for structure and conventions.
