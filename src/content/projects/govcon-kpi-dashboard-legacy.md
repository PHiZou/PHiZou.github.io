# GovCon analytics dashboard for mission KPIs

This project is about turning messy operational reporting into a clearer decision-support system.

## What I built

- A SQL-backed reporting layer with more consistent KPI logic
- Dashboard views for performance monitoring and trend analysis
- Recurring reporting workflows that reduced spreadsheet-heavy manual work
- A clearer structure for translating stakeholder questions into stable metrics

## Why it mattered

In mission-driven environments, analytics work often breaks down because definitions drift and reporting becomes hard to trust. The value here was creating something more consistent, more usable, and easier for leadership to act on.

## What this project shows

- stakeholder-facing analytics work
- KPI and reporting-layer design
- stronger metric consistency and decision support
- a bridge between analytics engineering and BI engineering
